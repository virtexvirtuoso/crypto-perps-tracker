💰 Funding Rates

GET /api/funding Funding rates from all exchanges
Description

Returns funding rates from all exchanges, sorted by rate, with volume-weighted average calculation.

Funding Rate Calculation

Annualized % is calculated assuming 8-hour funding intervals:
annualized = funding_rate × 100 × 3 × 365

🎯 Virtuoso Integration

GET /api/perpetuals-pulse Comprehensive market pulse for Virtuoso dashboard
Description

Returns comprehensive perpetual futures metrics optimized for the Virtuoso trading dashboard. Includes funding rates, open interest, long/short ratios, CEX/DEX split, and basis calculations.

Key Metrics
Metric Description
funding_rate Volume-weighted average funding rate across exchanges
open_interest Total open interest in USD
long_short_ratio Aggregated from OKX, Binance, Bybit
dex_volume_pct Percentage of volume on DEXs
basis Spot vs Futures price difference
Example Response
{
  "status": "success",
  "timestamp": "2025-12-17T22:35:26+00:00",
  "funding_rate": 0.0065,
  "funding_sentiment": "bullish",
  "open_interest": 50925157264.90,
  "oi_change_24h": 2.5,
  "long_short_ratio": 1.05,
  "dex_volume_pct": 9.45,
  "cex_volume_pct": 90.55,
  "basis": -0.0545,
  "basis_sentiment": "contango",
  "exchange_count": 12
}
