Funding Rates

GET /api/funding Funding rates from all exchanges
Description

Returns funding rates from all exchanges, sorted by rate, with volume-weighted average calculation.

Calculation

Annualized % = funding_rate × 100 × 3 × 365 (assuming 8-hour intervals)

Example Response
{
  "status": "success",
  "average_funding_rate": 0.0000527,
  "average_funding_pct": 0.00527,
  "exchanges": [
    {
      "exchange": "Gate.io",
      "funding_rate": 0.000088,
      "funding_rate_pct": 0.0088,
      "annualized_pct": 9.64,
      "volume_24h": 21058807349.00
    }
  ]
}

Tier 1: Direct Alpha Opportunities

GET /api/analysis/funding-arbitrage Cross-exchange funding rate arbitrage
Description

Identifies cross-exchange funding rate spreads for delta-neutral arbitrage opportunities.

Trading Signal
Condition Action
Spread > 0.005% (5.5% annualized) Execute delta-neutral position
Annualized return > 10% High priority opportunity

      "long_exchange": "Drift",
      "short_exchange": "Gate.io",
      "spread": 0.001451,
      "annualized_return_pct": 15.88
    }
  ]
}
GET /api/analysis/oi-price-divergence OI vs Price divergence detector
Description

Detects divergences between open interest changes and price movements - a leading indicator for potential reversals.

Signal Interpretation
Signal Meaning
BEARISH_DIVERGENCE Price rising but OI falling - weak rally
BULLISH_DIVERGENCE Price falling but OI rising - accumulation
GET /api/analysis/funding-extremity Extreme funding rate detector
Description

Identifies exchanges with extreme funding rates using z-score analysis - signals crowded positioning.

Z-Score Thresholds
Z-Score Signal
> 2.0 Extreme long crowding - fade longs
< -2.0 Extreme short crowding - fade shorts
